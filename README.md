# QCTO SDP Dashboard Project

## Overview
This project explores South Africa's accredited Skills Development Providers data from the QCTO database.

I built it to make it easier to identify providers that might potentially offer a learnership for a qualification I am interested in, while also making the data easier to explore through filters, maps, contact details, and career-path logic.

## Project Goals
- Clean and standardise the QCTO SDP dataset
- Build a Power BI dashboard for provider and qualification exploration
- Keep contact details visible for practical use
- Create a career-to-qualification mapping structure
- Prepare for a future HTML version of the project

## Why I Built This
The information is publicly available, but it is not always easy to filter, understand, or use practically when trying to find providers linked to qualifications and possible learnership opportunities.

This project started as a personal solution to that problem and grew into a full data cleaning, modelling, and dashboard design project.
